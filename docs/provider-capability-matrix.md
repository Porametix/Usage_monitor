## Safe polling policy

The MVP uses a 15-minute default for the live collector and one request cycle per interval. It retries only idempotent GETs, at most three attempts, with bounded backoff/jitter. A 401/403 is reported without retry. No fixed quota is assumed; obey Retry-After and the provider's current rate-limit documentation.
